# 图书管理系统

## 📋 项目简介
基于 Qt 框架开发的图书管理系统，实现了图书管理、读者管理、借阅管理等核心功能。

## 🚀 功能特性
### 📚 图书管理
- 图书信息增删改查
- 图书分类管理
- 库存状态监控

### 👥 读者管理  
- 读者信息管理
- 借阅权限设置
- 读者统计分析

### 🔄 借阅管理
- 图书借阅/归还
- 借阅历史记录
- 逾期提醒功能

### 📊 统计报表
- 借阅统计
- 图书使用率分析
- 读者活跃度统计

## 🛠️ 技术栈
- **开发框架**: Qt 6.5.3
- **编程语言**: C++
- **数据库**: SQLite
- **构建工具**: qmake
- **开发环境**: Qt Creator / Visual Studio
